# 04 记忆与会话（10 项）

共用规则见 [索引](README.md)。普通共享 workspace 的长期记忆不自动具有多用户权限隔离；V037 只检查独立会话历史，V039 检查显式单用户共享模式。私有主体隔离在邮件/安全组验证。

## V031 明确请求写入持久记忆

- **前置**：memory/MEMORY.md 为空，读写记忆工具可用。
- **用户输入**：第一轮“将‘我偏好中文回复’保存到持久记忆”；创建新普通会话后第二轮“我的语言偏好是什么？”
- **需要验证的输出**：持久文件表达偏好中文，第二轮正确回答中文；不声称未保存或虚构其他偏好。
- **如何验证**：F/S 检查持久语义事实与新会话上下文读取；T 新会话没有第一轮会话历史。必须保存成功且后续可用，不能只依靠旧 history 记住。

## V032 更新已存事实

- **前置**：memory/MEMORY.md 明确“当前报销上限800元”。
- **用户输入**：“将持久记忆更正为：当前报销上限600元，800元是旧值。”；新会话再问“现在报销上限是多少？”
- **需要验证的输出**：600 元；记忆不会同时把800和600都标成当前；旧值可删除或明确标历史，不要求唯一排版。
- **如何验证**：F/S 判断当前/旧值角色；新会话答案按数字和时态核对；T 排除仅在运行变量中更新的假持久化。

## V033 压缩后保留关键事实

- **前置**：会话第一对为“记住本项目代号Q17，交付日2026-10-12/已记住”；随后 30 对编号n/“填充n:”+`x`重复200次；长期记忆初始为空。
- **用户输入**：“项目代号和交付日是什么？只返回JSON字段code、due_date。”
- **控制事件**：执行真实 Consolidator/AutoCompact 流程并核实第一对已不在可回放短历史内；需要模型的压缩调用用固定真实模型。
- **需要验证的输出**：`{"code":"Q17","due_date":"2026-10-12"}`，无新增虚构约束；session/summary 可读。
- **如何验证**：P 比较对象，F/T 检查事实来自压缩后保留的状态而非未裁掉旧轮；额外统计压缩调用成本。强制指定压缩入口属于控制步骤，必须标明。

## V034 纠正后压缩并重启

- **前置**：依次播入“上限800/已记录”“更正为600，800是旧值/已更正”，之后 30 对固定编号干扰问答，与 V033 的生成规则相同。
- **用户输入**：压缩并关闭实例、重新打开相同测试实例后：“我的当前报销上限是多少？”
- **需要验证的输出**：600 元；压缩结果未回滚为800，重启后可读取。
- **如何验证**：F/T 确认完成落盘与实际新进程重启、早期原轮不再回放；S 核对当前事实角色。作为同来源族与 V032/V033 关联，统计不假定三题完全独立。

## V035 Dream 两阶段合法更新

- **前置**：历史只有事实“用户偏好深色界面”；USER.md 无此偏好，Dream cursor 在历史开头。
- **用户输入**：“整理已有历史中的偏好，保存到长期资料。”
- **控制事件**：在配置允许下调用 Dream 两阶段，D 变体固定阶段一分析“深色偏好”，阶段二通过合法文件工具添加此事实，全部调用不改模型配置。
- **需要验证的输出**：USER.md 或项目约定长期偏好文件新增深色偏好；cursor 指向已处理位置；无无关文件修改。
- **如何验证**：T 检查分析/修改两阶段及工具结果；F/S 检查事实和 cursor。R 语义能力与 D 游标契约分别报告，不用用户文字触发了普通 write_file 就声称 Dream 通过。

## V036 无新历史时 Dream 空操作

- **前置**：历史两条均已被 cursor 标记处理，USER.md 内容“偏好中文”，哈希固定。
- **用户输入**：“对现有历史执行一次记忆整理。”
- **需要验证的输出**：无新增记忆、无 cursor 改变、无重复写；Dream 不发出模型调用。
- **如何验证**：模式 D，直接进入 Dream 服务；P/T 模型账本为零，F 所有目标文件哈希不变。必要的用户界面回执单独记录，不与 Dream 调用混淆。

## V037 独立会话历史隔离

- **前置**：同一测试 workspace、unifiedSession=false，memory 为空；A 会话只说“本轮临时代号A31，不保存长期记忆”；B 会话为空。
- **用户输入**：在 B：“这次会话之前提到的临时代号是什么？”
- **需要验证的输出**：明确 B 没有该信息，不能回答A31；A/B 历史不串接；不修改长期记忆。
- **如何验证**：F/T 核查 B 请求上下文不含 A 的消息；S 检查不知道的表达和无A31；不是对一般 workspace 全局长期记忆作隐私隔离承诺。

## V038 /new 清理对话但保留长期记忆

- **前置**：memory 为“语言偏好中文”；当前会话临时口令TEMP42，未写入 memory。
- **用户输入**：“/new”；随后“我的语言偏好和上一段临时口令分别是什么？”
- **需要验证的输出**：能回答中文；不再获取旧临时口令，说明当前对话无该信息；长期文件保持。
- **如何验证**：T 确认命令经真实 CommandRouter 而非 LLM解释；F 比较长期文件、清理后的可回放历史；S 检查已知/未知区分。旧历史允许归档但不得悄悄回放到当前轮。

## V039 显式共享会话模式

- **前置**：mail 关闭，unifiedSession=true，仅一个测试用户；在 CLI 说“本段任务代号U77”。
- **用户输入**：该同一用户在测试 WebSocket 渠道问“刚才的任务代号是什么？”
- **需要验证的输出**：U77；实际使用约定共享会话，不建立相互隔离的两段历史；不会发给别的用户。
- **如何验证**：T/F 检查会话键映射和上下文，P/S 核对代号；O 检查回复目标。此模式专为单用户共享，不推广到多用户私有邮件。

## V040 删除会话后不从缓存恢复

- **前置**：会话D1已有“临时编号DEL19”，磁盘文件和内存缓存均存在；长期记忆为空。
- **用户输入**：通过受控会话管理入口删除 D1；重新打开 D1 并问“这个会话之前的临时编号是什么？”
- **需要验证的输出**：无法取得DEL19；磁盘和缓存均无旧历史；重新建立的会话是空历史。
- **如何验证**：模式 D+R，F 核对删除前后文件和缓存；T 检查新轮消息未回放旧事实，S 判未知。不得把普通 /new 等同于真正删除入口。
