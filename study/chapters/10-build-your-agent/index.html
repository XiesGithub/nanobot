Chapter 10 · Build your own agent

独立实现你的 Agent：从契约到可观察运行

目标是离开任何项目源码也能动手：先规定消息如何流转，再写验收测试，最后把 Provider、工具、循环和会话组合成一个可运行程序。本章提供一套独立教学实现；它不是 nanobot 源码摘录，也不要求安装 nanobot。

Python 3.11+ 标准库6 个实现模块12 个回归测试离线确定性运行
完成标志：输入 add 2 3 后，Provider 请求工具；Runner 校验、执行并把结果送回 Provider；最终得到 Result: 5。你能用 trace 解释每条消息，并证明异常有界、会话不串线、退出后可恢复。默认 ScriptedProvider 只是可预测的测试替身，没有任何真实 LLM、网络或密钥依赖，也不会读取 api.txt。

先写需求与不变量

  1. 用户输入只经 Runner 进入历史。Provider 返回决策，不能自行执行工具。
  2. 工具名称必须来自注册表；本例只实现“恰好两个有界整数”的 schema 子集，未知工具、缺失字段、额外字段、布尔值和越界数字均返回结构化错误。
  3. 一条 assistant 工具请求包含若干 Call；每个 Call 必须且只能对应一条带相同 ID 的 tool 消息；下一次 Provider 请求前配对完整。
  4. 默认每轮最多 4 次 Provider 请求，每次最多 4 个工具调用。最后一步也先补齐工具结果，再以 step_budget 终止。
  5. 按 session key 分隔文件，完成一轮后原子替换 JSON。存储损坏或写入失败不能伪装成成功。

本章把“一轮 turn”定义为一次用户输入引发的全部模型与工具往返；“step”是其中一次 Provider 请求。Provider 返回普通文本时回合完成，返回调用时继续。这个区别决定预算的计数位置。

先定接口，再决定模块依赖

文件公开接口输入 / 输出与职责
contracts.pyCall、Reply、ProviderCall = id/name/arguments；Reply = content/calls。共享契约不导入业务模块。
provider.pyasync complete(messages, schemas)接收历史副本与可用工具 schema，返回 Reply。ScriptedProvider 识别 add 指令和上一条工具结果。
tools.pyregister / schemas / execute统一登记名称、参数声明与可调用函数。执行前验证同一份 schema；错误返回 JSON，不向模型泄露异常文本。
runner.pyasync run(key, text)管理本轮历史、ID 集合和预算，返回 (answer, trace)。只在结束时写存储。
session.pyload(key) / save(key, messages)session key 经 SHA-256 变成固定文件名；验证解析后的路径仍位于存储目录；写临时文件、fsync，再 replace。
app.pymain()解析参数并装配具体对象。默认临时目录保证每次演示输出相同；指定 state-dir 才保留历史。

消息在存储中使用普通字典，便于直接 JSON 序列化；边界决策用 dataclass，便于识别错误类型。Provider 是 Protocol，因此替换适配器只需满足一个方法，无须继承庞大的框架。工具注册表刻意只支持本章所需 schema 子集，不是通用 JSON Schema 验证器。

默认输出与完整事件 trace

input: add 2 3
provider: step 1
request: call-1 add {"a": 2, "b": 3}
tool: add -> ok
provider: step 2
final: Result: 5
saved: 4 messages
answer: Result: 5

第一步只产生请求，不是答案。Runner 看到 call-1 后校验 add 的参数，调用纯函数；第二步 Provider 才看到 {"ok": true, "value": 5} 并生成答案。trace 是可观察事件摘要；实际完整协议保存在四条历史消息里：

[
  {"role":"user", "content":"add 2 3"},
  {"role":"assistant", "content":"", "tool_calls":[
    {"id":"call-1", "name":"add", "arguments":{"a":2,"b":3}}
  ]},
  {"role":"tool", "tool_call_id":"call-1", "content":"{\"ok\": true, \"value\": 5}"},
  {"role":"assistant", "content":"Result: 5"}
]

工具结果的 content 是 JSON 字符串，而不是嵌套消息；role 决定它是外部数据，tool_call_id 决定它回应哪个请求。不能把工具内容写成 user 或 system，否则会改变语义。遇到错误也保留配对，Provider 才有机会修正下一次调用。

"""A deliberately small schema subset: exactly two bounded integer arguments."""
import json
from copy import deepcopy


class ToolRegistry:
    def __init__(self):
        self._tools = {}

    def register(self, name, description, function):
        if name in self._tools:
            raise ValueError("duplicate tool name")
        parameters = {
            "type": "object",
            "properties": {
                key: {"type": "integer", "minimum": -1000000, "maximum": 1000000}
                for key in ("a", "b")
            },
            "required": ["a", "b"],
            "additionalProperties": False,
        }
        schema = {"name": name, "description": description, "parameters": parameters}
        self._tools[name] = (schema, function)

    def schemas(self):
        return [deepcopy(schema) for schema, _ in self._tools.values()]

    def execute(self, call):
        def failure(code):
            return json.dumps({"ok": False, "error": code})
        if call.name not in self._tools:
            return failure("unknown_tool")
        schema, function = self._tools[call.name]
        args = call.arguments
        parameters = schema["parameters"]
        if not isinstance(args, dict) or set(args) != set(parameters["required"]):
            return failure("invalid_arguments")
        for key, value in args.items():
            rule = parameters["properties"][key]
            # bool is a subclass of int in Python; exact type rejects True/False.
            if type(value) is not int or not rule["minimum"] <= value <= rule["maximum"]:
                return failure("invalid_arguments")
        try:
            return json.dumps({"ok": True, "value": function(**args)}, allow_nan=False)
        except Exception:
            return failure("tool_error")


def make_tools():
    registry = ToolRegistry()
    registry.register("add", "Add two integers between -1000000 and 1000000.",
                      lambda a, b: a + b)
    return registry

"""Single-writer JSON persistence. Caller owns the storage directory."""
import hashlib
import json
import os
import tempfile
from pathlib import Path


class SessionStore:
    def __init__(self, root):
        self.root = Path(root).resolve()
        self.root.mkdir(parents=True, exist_ok=True)

    def _path(self, key):
        if not isinstance(key, str) or not key:
            raise ValueError("session key must be nonempty text")
        name = hashlib.sha256(key.encode("utf-8")).hexdigest() + ".json"
        path = (self.root / name).resolve()
        if not path.is_relative_to(self.root):
            raise ValueError("session path escapes storage directory")
        return path

    def load(self, key):
        path = self._path(key)
        if not path.exists():
            return []
        data = json.loads(path.read_text(encoding="utf-8"))
        if (not isinstance(data, dict) or data.get("version") != 1
                or data.get("key") != key or not isinstance(data.get("messages"), list)):
            raise ValueError("invalid session envelope")
        for message in data["messages"]:
            if (not isinstance(message, dict)
                    or message.get("role") not in {"user", "assistant", "tool"}
                    or not isinstance(message.get("content"), str)):
                raise ValueError("invalid stored message")
        return data["messages"]

    def save(self, key, messages):
        path = self._path(key)
        payload = json.dumps({"version": 1, "key": key, "messages": messages},
                             ensure_ascii=False, indent=2)
        temporary = None
        try:
            with tempfile.NamedTemporaryFile(mode="w", encoding="utf-8", dir=self.root,
                                             suffix=".tmp", delete=False) as stream:
                temporary = Path(stream.name)
                stream.write(payload)
                stream.flush()
                os.fsync(stream.fileno())
            os.replace(temporary, path)
        finally:
            if temporary is not None:
                temporary.unlink(missing_ok=True)

"""Deterministic teaching provider. No network, model request, or credential."""
import json

from contracts import Call, Reply


class ScriptedProvider:
    async def complete(self, messages, schemas):
        last = messages[-1]
        if last["role"] == "tool":
            result = json.loads(last["content"])
            if result["ok"]:
                return Reply(content=f"Result: {result['value']}")
            return Reply(content=f"Tool error: {result['error']}")
        parts = last["content"].split()
        if len(parts) == 3 and parts[0] == "add":
            try:
                a, b = int(parts[1]), int(parts[2])
            except ValueError:
                return Reply(content="Usage: add INTEGER INTEGER")
            return Reply(calls=[Call(f"call-{len(messages)}", "add", {"a": a, "b": b})])
        return Reply(content="Usage: add INTEGER INTEGER")

"""The only module allowed to turn provider requests into tool execution."""
import asyncio
import json
from copy import deepcopy
from dataclasses import asdict

from contracts import Call, Provider, Reply


class Runner:
    def __init__(self, provider: Provider, tools, store, max_steps=4,
                 max_calls_per_step=4, provider_timeout=5.0):
        if max_steps < 1 or max_calls_per_step < 1 or provider_timeout <= 0:
            raise ValueError("budgets must be positive")
        self.provider, self.tools, self.store = provider, tools, store
        self.max_steps = max_steps
        self.max_calls_per_step = max_calls_per_step
        self.provider_timeout = provider_timeout

    async def run(self, key, text):
        messages = self.store.load(key)
        messages.append({"role": "user", "content": text})
        trace = [f"input: {text}"]
        seen_ids = {call["id"] for message in messages
                    for call in message.get("tool_calls", [])}

        def finish(content):
            messages.append({"role": "assistant", "content": content})
            self.store.save(key, messages)
            trace.append(f"final: {content}")
            trace.append(f"saved: {len(messages)} messages")
            return content, trace

        for step in range(1, self.max_steps + 1):
            trace.append(f"provider: step {step}")
            try:
                reply = await asyncio.wait_for(
                    self.provider.complete(deepcopy(messages), self.tools.schemas()),
                    timeout=self.provider_timeout,
                )
            except TimeoutError:
                return finish("Stopped: provider_timeout")
            except Exception:
                return finish("Stopped: provider_error")
            if (not isinstance(reply, Reply) or not isinstance(reply.content, str)
                    or not isinstance(reply.calls, list)):
                return finish("Stopped: invalid_reply")
            if not reply.calls:
                return finish(reply.content)
            ids = []
            for call in reply.calls:
                if (not isinstance(call, Call) or not isinstance(call.id, str) or not call.id
                        or not isinstance(call.name, str) or not call.name):
                    return finish("Stopped: invalid_tool_calls")
                ids.append(call.id)
            if (len(ids) > self.max_calls_per_step or len(set(ids)) != len(ids)
                    or seen_ids.intersection(ids)):
                return finish("Stopped: invalid_tool_calls")
            # Reject the whole invalid batch before adding a protocol record or executing.
            seen_ids.update(ids)
            messages.append({"role": "assistant", "content": reply.content,
                             "tool_calls": [asdict(call) for call in reply.calls]})
            for call in reply.calls:
                trace.append(f"request: {call.id} {call.name} {json.dumps(call.arguments)}")
                result = self.tools.execute(call)
                messages.append({"role": "tool", "tool_call_id": call.id, "content": result})
                status = "ok" if json.loads(result)["ok"] else "error"
                trace.append(f"tool: {call.name} -> {status}")
        # Even the final allowed batch receives all tool results before stopping.
        return finish("Stopped: step_budget")

"""CLI composition root; copy this whole directory anywhere to run it."""
import argparse
import asyncio
from pathlib import Path
from tempfile import TemporaryDirectory

from provider import ScriptedProvider
from runner import Runner
from session import SessionStore
from tools import make_tools


async def execute(args, root):
    runner = Runner(ScriptedProvider(), make_tools(), SessionStore(root))
    answer, trace = await runner.run(args.session, args.text)
    for event in trace:
        print(event)
    print("answer:", answer)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("text", nargs="?", default="add 2 3")
    parser.add_argument("--session", default="demo")
    parser.add_argument("--state-dir", type=Path,
                        help="Persist state here; default uses a temporary demo directory.")
    args = parser.parse_args()
    if args.state_dir is None:
        with TemporaryDirectory(prefix="mini-agent-") as directory:
            asyncio.run(execute(args, Path(directory)))
    else:
        asyncio.run(execute(args, args.state_dir))


if __name__ == "__main__":
    main()

"""Run with: conda run -n nanobot python -m unittest discover -s . -v"""
import asyncio
import json
import tempfile
import unittest
from pathlib import Path

from contracts import Call, Reply
from provider import ScriptedProvider
from runner import Runner
from session import SessionStore
from tools import make_tools


class FixedProvider:
    def __init__(self, reply):
        self.reply = reply

    async def complete(self, messages, schemas):
        return self.reply


class AgentTests(unittest.TestCase):
    def setUp(self):
        self.temp = tempfile.TemporaryDirectory()
        self.addCleanup(self.temp.cleanup)
        self.root = Path(self.temp.name)
        self.store = SessionStore(self.root)

    def run_turn(self, provider=None, key="demo", text="add 2 3", **limits):
        agent = Runner(provider or ScriptedProvider(), make_tools(), self.store, **limits)
        return asyncio.run(agent.run(key, text))

    def test_tool_round_trip_and_call_id(self):
        answer, trace = self.run_turn()
        self.assertEqual(answer, "Result: 5")
        messages = self.store.load("demo")
        self.assertEqual([m["role"] for m in messages],
                         ["user", "assistant", "tool", "assistant"])
        self.assertEqual(messages[1]["tool_calls"][0]["id"], messages[2]["tool_call_id"])
        self.assertEqual(json.loads(messages[2]["content"]), {"ok": True, "value": 5})
        self.assertIn("tool: add -> ok", trace)

    def test_invalid_arguments_do_not_execute(self):
        registry = make_tools()
        for args in ({"a": True, "b": 3}, {"a": "2", "b": 3}, {"a": 2},
                     {"a": 2, "b": 3, "extra": 1}, {"a": 1000001, "b": 1}, []):
            result = json.loads(registry.execute(Call("x", "add", args)))
            self.assertFalse(result["ok"])
            self.assertEqual(result["error"], "invalid_arguments")

    def test_unknown_tool(self):
        result = json.loads(make_tools().execute(Call("x", "shell", {})))
        self.assertEqual(result["error"], "unknown_tool")

    def test_error_result_returns_to_provider(self):
        class Recovering:
            async def complete(self, messages, schemas):
                if messages[-1]["role"] == "tool":
                    error = json.loads(messages[-1]["content"])["error"]
                    return Reply(content="Observed: " + error)
                return Reply(calls=[Call("bad-1", "missing", {})])
        answer, _ = self.run_turn(Recovering())
        self.assertEqual(answer, "Observed: unknown_tool")

    def test_step_budget_closes_pending_calls(self):
        answer, trace = self.run_turn(max_steps=1)
        self.assertEqual(answer, "Stopped: step_budget")
        self.assertEqual(self.store.load("demo")[-2]["role"], "tool")
        self.assertEqual(sum(t.startswith("provider:") for t in trace), 1)

    def test_call_batch_budget(self):
        reply = Reply(calls=[Call(str(i), "add", {"a": 1, "b": 2}) for i in range(5)])
        answer, _ = self.run_turn(FixedProvider(reply))
        self.assertEqual(answer, "Stopped: invalid_tool_calls")
        self.assertFalse(any(m["role"] == "tool" for m in self.store.load("demo")))

    def test_duplicate_call_id_rejected_before_execution(self):
        call = Call("same", "add", {"a": 1, "b": 2})
        answer, _ = self.run_turn(FixedProvider(Reply(calls=[call, call])))
        self.assertEqual(answer, "Stopped: invalid_tool_calls")

    def test_provider_exception_is_bounded(self):
        class Broken:
            async def complete(self, messages, schemas):
                raise RuntimeError("private diagnostics must not enter history")
        answer, _ = self.run_turn(Broken())
        self.assertEqual(answer, "Stopped: provider_error")
        self.assertNotIn("private", json.dumps(self.store.load("demo")))

    def test_session_isolation_and_safe_paths(self):
        self.run_turn(key="../alice", text="add 2 3")
        self.run_turn(key="bob", text="add 8 9")
        self.assertEqual(self.store.load("../alice")[-1]["content"], "Result: 5")
        self.assertEqual(self.store.load("bob")[-1]["content"], "Result: 17")
        self.assertEqual(len(list(self.root.glob("*.json"))), 2)

    def test_restart_restores_history(self):
        self.run_turn()
        fresh = SessionStore(self.root)
        self.assertEqual(fresh.load("demo"), self.store.load("demo"))
        answer, _ = asyncio.run(Runner(ScriptedProvider(), make_tools(), fresh)
                              .run("demo", "add 10 20"))
        self.assertEqual(answer, "Result: 30")
        self.assertEqual(len(fresh.load("demo")), 8)

    def test_corrupt_file_is_not_silently_reset(self):
        self.run_turn()
        next(self.root.glob("*.json")).write_text("{broken", encoding="utf-8")
        with self.assertRaises(ValueError):
            self.store.load("demo")

    def test_tool_exception_becomes_error(self):
        registry = make_tools()
        def broken(a, b):
            raise RuntimeError("private")
        registry.register("broken", "fail for testing", broken)
        result = json.loads(registry.execute(Call("x", "broken", {"a": 1, "b": 2})))
        self.assertEqual(result, {"ok": False, "error": "tool_error"})


if __name__ == "__main__":
    unittest.main()

实现中的取舍与故障边界

  1. 协议先验证，副作用后执行。重复 ID、空 ID 或超大调用批次在写入 assistant 请求前整体拒绝；已接纳的每条调用包括未知工具、非法参数都补一条结果。seen_ids 覆盖已有历史，避免后续回合复用 ID。
  2. 预算有多个维度。示例限制 Provider 步数、单步工具数和 Provider 等待时间（5 秒），正常最多执行 16 个工具。本地工具同步执行，只适用于这里的短小纯计算；它没有通用工具超时、token 预算或输出字节预算，不能据此宣称任意插件都安全。
  3. 错误分层。参数与工具失败进入 tool 消息；Provider 异常/超时变成停止文本并保存；存储损坏和写入失败向调用者抛出，因为没有可靠落盘时不能报告成功。CancelledError 不被 Exception 捕获，取消会继续向上传播。
  4. 完成时提交。临时文件 flush + fsync + replace 防止半个 JSON 覆盖旧状态；取消或进程在提交前退出会丢失当前轮。此演示没有目录 fsync、日志恢复或事务数据库，不能保证断电后的全部持久性，也没有跨进程锁。同一个目录只允许单写入者；持久化头部和消息角色检查不等于验证所有历史协议。
  5. 隔离不等于鉴权。散列文件名与 resolve 检查防止把 session key 当路径；真实 Channel 还必须由可信身份构造 key，不能让客户指定别人的 key。存储目录应只由服务账户控制。
  6. 测试替身使流程可重复。ScriptedProvider 不理解任意自然语言，不证明真实模型准确率。它只让协议、循环和失败条件可以离线复现；真实模型的质量需要另做评测。当前 Runner 将没有工具调用的 Reply 视为完成，即使 content 是空字符串；若产品需要可见答案，应在 Provider 适配器或 Runner 增加“空文本有限重试/明确失败”的语义策略，并测试次数耗尽后的反馈，不能无限重试。

六轮迭代：把最小闭环扩展为自己的系统

每轮先写以下验收，再按参考设计动手。所有任务均从本页接口出发，不需要寻找 nanobot 的实现；本节描述的是待做扩展，未包含在默认示例中。

  1. 迭代 1：接入真实网络 Provider

    目标：Runner 与 tools 不变，把 ScriptedProvider 替换成一个 HTTP 适配器。先用伪造 HTTP 响应测试，再选择真实服务。

    逐步参考设计与验收

    ① 给适配器注入 transport、endpoint 和密钥读取函数；真实凭据只在需要时从受控文件或环境读取，不能写入历史与日志。② 请求中模型 ID 固定为 deepseek-v4-flash；把内部 Call 映射成服务端 function tool 格式。③ 检查 HTTP 状态、响应类型、tool name、call ID，并显式 JSON 解码 arguments；非法 JSON 作为 Provider 协议错误结束。④ 设置连接/读取超时，仅对适合重试的失败做有限退避；区分连接失败与响应丢失，避免盲目重试有副作用的操作。⑤ 建立测例：fake transport 检查模型 ID 和 schema；200 + tool_calls 经 Runner 得到对应 tool_call_id；429 后成功最多尝试约定次数；坏 JSON/超时都有限结束。验收日志只含状态和 request ID，不含密钥。默认测试仍全部离线。

  2. 迭代 2：添加 Channel 与消息总线

    目标：让控制台输入和另一种渠道共享同一个 Runner，同时保证同会话串行。

    逐步参考设计与验收

    ① 定义 Inbound(channel, account, chat, sender, text, event_id) 与 Outbound(target, text, reply_to)。② Channel 只做校验、身份映射、入队和发送；由可信字段构造稳定 session key，别直接信任客户端传入的 key。③ 用有界 asyncio.Queue 吸收消息；消费者从队列分配任务，用每个 key 一把 Lock，跨 key 可并行。④ outbound 保存原路由，不从模型输出推断接收人。⑤ 测试两渠道各发一条消息，答案回到各自目标；同 key 的两个延迟请求按序追加；一个慢 key 不阻塞其他 key；队列满时显示明确背压行为。若要多进程消费，升级存储事务与锁后再启用。

  3. 迭代 3：上下文压缩与长期记忆

    目标：限制发送给 Provider 的历史长度，同时保留可追溯的完整记录。

    逐步参考设计与验收

    ① 把完整事件日志与“本轮发送视图”分开；只压缩已完成的整轮，不能切断 assistant/tool 配对。② 用字符估算器先实现阈值，并为响应和工具结果预留预算；以后换 tokenizer，不改变策略接口。③ 保存 summary、covered_until、source_message_ids 和版本，原始日志不删除。④ 长期记忆单独保存可复用事实及来源，不把临时工具输出自动升格为系统指令。⑤ 构造 100 轮历史，确认上下文低于阈值、最新问题和整组调用仍在；压缩失败时不提交覆盖范围；重启读回同一摘要；alice 记忆永不进入 bob 的请求。用假 summarizer 测结构，再为真实摘要质量设计评测。

  4. 迭代 4：后台任务与 cron 调度

    目标：用户能登记稍后执行的任务，不占用当前对话回合等待。

    逐步参考设计与验收

    ① 定义 Job(id, owner, payload, due_at_utc, status, attempts, idempotency_key)，先支持单次到期；周期规则是后续适配层。② 工具只创建 Job 并返回 job ID，调度器另行领取与执行。③ 状态按 pending → running → succeeded/failed/cancelled 转移，持久化租约用于崩溃后重新领取。④ 结果通过 outbound 投递到原拥有者，给投递设去重键；不要宣称仅靠重试能实现 exactly-once。⑤ 用可注入时钟测试未到期不执行、到期只领取一次、进程重启恢复 pending、同一次投递重复尝试能去重；失败次数耗尽进入 failed。时区显示与内部 UTC 计算分离。

  5. 迭代 5：受限 subagent

    目标：父任务拆出独立子任务，得到结构化结果，而不是共享一个可任意修改的历史列表。

    逐步参考设计与验收

    ① 定义 ChildTask(id, parent_id, objective, depth, deadline, allowed_tools)，创建独立 session key 与最小上下文快照。② 子 Runner 只获得工具白名单，并设置并发数、最大深度和共享总预算。③ spawn 立即返回 ID，子任务完成后发布一次 Result(id, status, content)，父 Agent 在安全边界消费。④ 父子写各自记录，不共用可变消息对象；总预算采用原子扣减，防止并行倍增费用。⑤ 测试两个子任务互不见历史、无权限工具被拒绝、深度超限不创建、父任务终止能取消子任务、重复完成事件不重复注入。

  6. 迭代 6：取消、超时与工具安全

    目标：从纯加法扩展到有副作用工具前，建立可测试的授权与生命周期边界。

    逐步参考设计与验收

    ① 维护 session → 当前 task 的映射，控制命令走优先入口；取消后仍在 finally 释放锁并更新任务状态，不能吞掉 CancelledError。② 对网络调用配置超时，对不可协作取消的阻塞任务使用受控子进程；取消 asyncio 包装器并不等于停止后台线程。③ 文件工具先 resolve 并检查 allowed root，拒绝路径穿越与符号链接逃逸；网络工具先验证目标地址并在重定向后重新检查，禁止访问私网/元数据地址；shell 需要单独隔离和最小权限。④ 有副作用动作在模型请求之外执行权限/确认策略，并使用幂等键与审计事件；工具文本始终作为不可信数据。⑤ 测试取消慢 Provider 后不会执行下一工具；取消后同 key 可以再次运行；越界路径、重定向到内网、未授权写操作都在副作用前拒绝；一次已提交副作用在响应丢失重试时不会重复。此能力完成前只开放本例短小纯函数工具。
