后端暴露结构化列表

认证后的 GET /api/commands 返回 builtin_command_palette()，字段包含 command、title、description、icon 和 arg_hint。

REST 端点要求 API token

未认证请求得到 401。这里暴露的是用户界面元数据，不是一个“执行命令”的管理 API。

前端隐藏 stop/restart

listSlashCommands 主动过滤两项高影响命令；其他命令由 ThreadComposer 按命令、标题、描述和本地化文本搜索，最多显示 8 个。

选择只修改输入框

有 argHint 的命令填成 command + 空格 等待参数；无参数命令填入名称。用户仍需提交，不会因点击菜单立即执行。

执行路径回归统一总线

提交后和普通文本一样通过 WebSocket 形成 InboundMessage，AgentLoop 才进行命令识别。前端不是安全边界，手工输入隐藏命令仍会发往后端。

Telegram：菜单、正则与规范化

发现
BOT_COMMANDS→ set_my_commands
接收
MessageHandler Regex→ 权限检查→ 去掉 @bot
规范化
dream_log → dream-logdream_restore → dream-restore
执行
_handle_message→ MessageBus→ AgentLoop

/start 和 /help 在 Telegram Channel 内本地响应；其余被选中的命令经 _forward_command 进入统一 AgentLoop。转发时不会混入 reply-to 上下文，避免命令字符串被引用消息污染。

当前源码中的渠道漂移：BOT_COMMANDS 宣传了 /history，共享 help 也会列出它，但 Telegram 注册的转发正则没有包含 history，而通用消息 Handler 又排除了 filters.COMMAND。因此在当前实现中，Telegram 的 /history 菜单项很可能无法进入 AgentLoop。这正说明菜单、正则和 Router 三份表需要联动测试。

新增命令的推荐步骤

示例：/ping先定义最小 Handler
async def cmd_ping(ctx: CommandContext) -> OutboundMessage:
    return OutboundMessage(
        channel=ctx.msg.channel,
        chat_id=ctx.msg.chat_id,
        content="pong",
        metadata=dict(ctx.msg.metadata or {}),
    )

# register_builtin_commands
router.exact("/ping", cmd_ping)
  1. 在 builtin.py 编写异步 Handler，明确它是只读、会话副作用还是进程级副作用。
  2. 选择 tier：只有必须抢占运行中 Turn 的控制/观察动作才注册 priority；带参数命令同时考虑 exact 与带空格 prefix。
  3. 向 BUILTIN_COMMAND_SPECS 添加标题、描述、图标和 arg_hint，使 WebUI 与共享 help 自动发现。
  4. 审查渠道：WebUI 通常自动出现；Telegram 还要更新 BOT_COMMANDS、Regex 与必要的别名规范化。
  5. 测试 Router 匹配、busy-session 直派、参数边界、Handler 副作用、API metadata 与渠道转发。

选择 tier 的决策表

问题选择示例
必须在当前 Turn 结束前生效？priority exact/stop、/restart
忙碌时要立即读状态？priority + exact（如需普通 dispatch 完备）/status
命令必须完全相等？exact/new、/help、/dream
可选/必选尾部参数？exact + prefix("/cmd ")/history、/dream-log
由动态运行状态决定是否接管？interceptor接口已预留；默认尚未使用

  • 为什么 WebUI palette 不是命令安全边界？
    查看答案收起答案

    palette 只是客户端发现和填充 UI，用户仍可绕过它直接发送任意文本。真正的匹配、tier、权限和副作用都必须由后端 CommandRouter、Handler 与 Channel 鉴权执行。

  • Telegram 为什么需要把下划线别名转回连字符？
    查看答案收起答案

    Telegram BotCommand 菜单名不接受连字符，因而公开 dream_log/dream_restore；进入核心前 Channel 将它们规范化为 Router 注册的 /dream-log 和 /dream-restore。

  • 新增带参数命令时至少要同步哪些位置？
    查看答案收起答案

    至少同步 Handler、Router 的 exact 与带空格 prefix 注册、BUILTIN_COMMAND_SPECS 展示元数据，以及需要显式命令表/正则/别名的渠道（尤其 Telegram）；同时补匹配、args 和忙碌期测试。
