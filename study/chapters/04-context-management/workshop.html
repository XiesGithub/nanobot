1. ContextBuilder.build_system_prompt

system 是多种来源的显式组合；来源顺序、是否加载全文和长度上限都会改变模型行为。

当前源码原文 · nanobot/agent/context.py · ContextBuilder.build_system_prompt · 第 37–76 行（连续摘录）

    def build_system_prompt(
        self,
        skill_names: list[str] | None = None,
        channel: str | None = None,
        session_summary: str | None = None,
    ) -> str:
        """Build the system prompt from identity, bootstrap files, memory, and skills."""
        parts = [self._get_identity(channel=channel)]

        bootstrap = self._load_bootstrap_files()
        if bootstrap:
            parts.append(bootstrap)

        memory = self.memory.get_memory_context()
        if memory and not self._is_template_content(self.memory.read_memory(), "memory/MEMORY.md"):
            parts.append(f"# Memory\n\n{memory}")

        always_skills = self.skills.get_always_skills()
        if always_skills:
            always_content = self.skills.load_skills_for_context(always_skills)
            if always_content:
                parts.append(f"# Active Skills\n\n{always_content}")

        skills_summary = self.skills.build_skills_summary(exclude=set(always_skills))
        if skills_summary:
            parts.append(render_template("agent/skills_section.md", skills_summary=skills_summary))

        entries = self.memory.read_unprocessed_history(since_cursor=self.memory.get_last_dream_cursor())
        if entries:
            capped = entries[-self._MAX_RECENT_HISTORY:]
            history_text = "\n".join(
                f"- [{e['timestamp']}] {e['content']}" for e in capped
            )
            history_text = truncate_text(history_text, self._MAX_HISTORY_CHARS)
            parts.append("# Recent History\n\n" + history_text)

        if session_summary:
            parts.append(f"[Archived Context Summary]\n\n{session_summary}")

        return "\n\n---\n\n".join(parts)
  1. 先 identity，再存在的 bootstrap 文件，再非默认模板的 Memory。Memory 空或与内置模板相同则不插入，避免占位文字污染回答。
  2. always skills 加载全文；其余技能做摘要索引，并在 summary 中排除 always 项，避免重复付费。签名里的 skill_names 在当前函数体没有被直接使用，不能把传参当成实际已加载。
  3. 未被 Dream 消费的历史只取末50条，拼接时间与内容后再按32000字符截断；session_summary 另作为 Archived Context Summary 附加。
  4. 最终用分隔线连接 parts。这里没有对整个 system 统一 token 截断，因此单个大 bootstrap 文件仍可能成为总预算压力来源。

2. Session.get_history：选择与净化回放

磁盘消息包含持久化字段，不应直接作为 SDK 请求。第一段先得到合法的回放候选，再投影成模型字段。

当前源码原文 · nanobot/session/manager.py · Session.get_history：选择与净化回放 · 第 87–144 行（连续摘录）

    def get_history(
        self,
        max_messages: int = 120,
        *,
        max_tokens: int = 0,
        include_timestamps: bool = False,
    ) -> list[dict[str, Any]]:
        """Return unconsolidated messages for LLM input.

        History is sliced by message count first (``max_messages``), then by
        token budget from the tail (``max_tokens``) when provided.
        """
        unconsolidated = self.messages[self.last_consolidated:]
        max_messages = max_messages if max_messages > 0 else 120
        sliced = unconsolidated[-max_messages:]

        # Avoid starting mid-turn when possible, except for proactive
        # assistant deliveries that the user may be replying to.
        for i, message in enumerate(sliced):
            if message.get("role") == "user":
                start = i
                if i > 0 and sliced[i - 1].get("_channel_delivery"):
                    start = i - 1
                sliced = sliced[start:]
                break

        # Drop orphan tool results at the front.
        start = find_legal_message_start(sliced)
        if start:
            sliced = sliced[start:]

        out: list[dict[str, Any]] = []
        for message in sliced:
            content = message.get("content", "")
            role = message.get("role")
            if role == "assistant" and isinstance(content, str):
                content = _sanitize_assistant_replay_text(content)
            # Synthesize an ``[image: path]`` breadcrumb from the persisted
            # ``media`` kwarg so LLM replay still sees *something* where the
            # image used to be. Without this, an image-only user turn
            # replays as an empty user message — the assistant's reply then
            # looks like it's responding to nothing.
            media = message.get("media")
            if role == "user" and isinstance(media, list) and media and isinstance(content, str):
                breadcrumbs = "\n".join(
                    image_placeholder_text(p) for p in media if isinstance(p, str) and p
                )
                content = f"{content}\n{breadcrumbs}" if content else breadcrumbs
            if include_timestamps:
                content = self._annotate_message_time(message, content)
            if role == "assistant" and isinstance(content, str) and not content.strip():
                if not any(key in message for key in ("tool_calls", "reasoning_content", "thinking_blocks")):
                    continue
            entry: dict[str, Any] = {"role": message["role"], "content": content}
            for key in ("tool_calls", "tool_call_id", "name", "reasoning_content", "thinking_blocks"):
                if key in message:
                    entry[key] = message[key]
            out.append(entry)
  1. 从 last_consolidated 开始取未归档后缀，max_messages<=0 会回退120，再按条数取尾部。首次 user 之前尽量剔除，但紧邻 user 的主动渠道投递可保留。
  2. find_legal_message_start 修剪前端孤立工具结果。assistant 文字先清理回放噪声，纯空 assistant 且无调用/推理字段时跳过。
  3. 用户图片用 media 合成文字 breadcrumb，避免历史图像输入变成空问句；include_timestamps 决定是否附加时间。
  4. 只复制 role/content 与 tool_calls、tool_call_id、name、reasoning_content、thinking_blocks 等白名单字段。Session metadata 不会通过字典全量扩散到模型。

3. Session.get_history：token 尾部选择

从新到旧保留历史可以保护最近意图，但只取最后 assistant 可能失去它回答的问题。

  3. 最后再找合法工具边界。该函数返回新列表，不把裁剪结果直接写回 Session；不要把一次 prompt 限制误当成删除用户存档。

4. ContextBuilder.build_messages

把当前用户文本和运行元数据合为一次输入，并保持多模态列表结构。

当前源码原文 · nanobot/agent/context.py · ContextBuilder.build_messages · 第 140–172 行（连续摘录）

    def build_messages(
        self,
        history: list[dict[str, Any]],
        current_message: str,
        skill_names: list[str] | None = None,
        media: list[str] | None = None,
        channel: str | None = None,
        chat_id: str | None = None,
        current_role: str = "user",
        sender_id: str | None = None,
        session_summary: str | None = None,
    ) -> list[dict[str, Any]]:
        """Build the complete message list for an LLM call."""
        runtime_ctx = self._build_runtime_context(channel, chat_id, self.timezone, sender_id=sender_id)
        user_content = self._build_user_content(current_message, media)

        # Merge runtime context and user content into a single user message
        # to avoid consecutive same-role messages that some providers reject.
        if isinstance(user_content, str):
            merged = f"{runtime_ctx}\n\n{user_content}"
        else:
            merged = [{"type": "text", "text": runtime_ctx}] + user_content
        messages = [
            {"role": "system", "content": self.build_system_prompt(skill_names, channel=channel, session_summary=session_summary)},
            *history,
        ]
        if messages[-1].get("role") == current_role:
            last = dict(messages[-1])
            last["content"] = self._merge_message_content(last.get("content"), merged)
            messages[-1] = last
            return messages
        messages.append({"role": current_role, "content": merged})
        return messages
  1. _build_runtime_context 产生带 metadata-only 标签的时间、渠道和用户标识；_build_user_content 产生文本或图片块。标签区分语义，但不是程序级权限隔离。
  2. 纯文本前加 runtime 块，多模态则先放一个 runtime text block，再保留全部 user_content。构造 system+history 后再处理当前角色。
  3. 若最后一条 role 等于 current_role，浅复制该消息字典，合并 content 并替换末项；不是再 append 一个同角色消息。str+str 用空行连接，有列表时规范成 blocks 拼接。
  4. 否则 append 当前角色消息。浅复制保护了本函数修改的顶层 content，不能据此宣称整个嵌套历史已深拷贝。

5. ContextBuilder._build_user_content

二进制图片只在本轮请求时编码；工具/持久化阶段还需要保留可以识别来源的元信息。

当前源码原文 · nanobot/agent/context.py · ContextBuilder._build_user_content · 第 174–197 行（连续摘录）

    def _build_user_content(self, text: str, media: list[str] | None) -> str | list[dict[str, Any]]:
        """Build user message content with optional base64-encoded images."""
        if not media:
            return text

        images = []
        for path in media:
            p = Path(path)
            if not p.is_file():
                continue
            raw = p.read_bytes()
            mime = detect_image_mime(raw) or mimetypes.guess_type(path)[0]
            if not mime or not mime.startswith("image/"):
                continue
            b64 = base64.b64encode(raw).decode()
            images.append({
                "type": "image_url",
                "image_url": {"url": f"data:{mime};base64,{b64}"},
                "_meta": {"path": str(p)},
            })

        if not images:
            return text
        return images + [{"type": "text", "text": text}]
  1. 没有 media 直接返回 text；遍历路径时先检查 is_file，读取 bytes，用实际图片探测优先于文件扩展名猜测。
  2. MIME 必须以 image/ 开头才编码为 data URL；同时添加内部 _meta.path，供后续处理追踪本地来源。它不应作为厂商协议字段直传。
  3. 所有附件均无效时仍返回纯文本；有图片则返回 images + 最后文本块。文件读异常会传播，这段不是通用文档抽取器，也没有重新执行 allowed_dir 安全判定。

6. AgentRunner._drop_orphan_tool_results

历史截断或异常中断可能留下有结果而没有声明的消息。发送给模型之前先删掉这种没有依据的结果。

当前源码原文 · nanobot/agent/runner.py · AgentRunner._drop_orphan_tool_results · 第 997–1020 行（连续摘录）

    def _drop_orphan_tool_results(
        messages: list[dict[str, Any]],
    ) -> list[dict[str, Any]]:
        """Drop tool results that have no matching assistant tool_call earlier in the history."""
        declared: set[str] = set()
        updated: list[dict[str, Any]] | None = None
        for idx, msg in enumerate(messages):
            role = msg.get("role")
            if role == "assistant":
                for tc in msg.get("tool_calls") or []:
                    if isinstance(tc, dict) and tc.get("id"):
                        declared.add(str(tc["id"]))
            if role == "tool":
                tid = msg.get("tool_call_id")
                if tid and str(tid) not in declared:
                    if updated is None:
                        updated = [dict(m) for m in messages[:idx]]
                    continue
            if updated is not None:
                updated.append(dict(msg))

        if updated is None:
            return messages
        return updated
  1. 顺序扫描 assistant.tool_calls，把有效 id 放进 declared。只有前面已经出现的声明才能为后面的结果提供依据。
  2. 遇 tool 且有 tid 但不在 declared，就从该条开始构建 updated 副本并跳过；原序列前半段只在首次需要修改时复制。
  3. 没有修改则返回原列表，减少分配；本函数不验证所有复杂顺序，也不删除缺失/空 tid 的结果，因此它只是协议治理的一道防线。

7. AgentRunner._backfill_missing_tool_results

声明存在而结果缺失时，删掉声明会丢失已发生的意图；补错误结果让模型知道该次调用没有可用输出。

当前源码原文 · nanobot/agent/runner.py · AgentRunner._backfill_missing_tool_results · 第 1023–1061 行（连续摘录）

    def _backfill_missing_tool_results(
        messages: list[dict[str, Any]],
    ) -> list[dict[str, Any]]:
        """Insert synthetic error results for orphaned tool_use blocks."""
        declared: list[tuple[int, str, str]] = []  # (assistant_idx, call_id, name)
        fulfilled: set[str] = set()
        for idx, msg in enumerate(messages):
            role = msg.get("role")
            if role == "assistant":
                for tc in msg.get("tool_calls") or []:
                    if isinstance(tc, dict) and tc.get("id"):
                        name = ""
                        func = tc.get("function")
                        if isinstance(func, dict):
                            name = func.get("name", "")
                        declared.append((idx, str(tc["id"]), name))
            elif role == "tool":
                tid = msg.get("tool_call_id")
                if tid:
                    fulfilled.add(str(tid))

        missing = [(ai, cid, name) for ai, cid, name in declared if cid not in fulfilled]
        if not missing:
            return messages

        updated = list(messages)
        offset = 0
        for assistant_idx, call_id, name in missing:
            insert_at = assistant_idx + 1 + offset
            while insert_at < len(updated) and updated[insert_at].get("role") == "tool":
                insert_at += 1
            updated.insert(insert_at, {
                "role": "tool",
                "tool_call_id": call_id,
                "name": name,
                "content": _BACKFILL_CONTENT,
            })
            offset += 1
        return updated
  1. 第一遍记录声明的 assistant 下标、call_id、工具名，同时收集已返回结果的 fulfilled 集合。缺失列表取 declared 中不在 fulfilled 的项。
  2. 没有缺失时原样返回；否则在原 assistant 后定位插入处，跳过紧邻现有 tool 消息，再插入 _BACKFILL_CONTENT。offset 校正之前新增条目引起的下标变化。
  3. 补的是协议占位，绝不再次执行工具。算法按 id 匹配，因此 call_id 全局唯一是调用方的重要前提；错误复用 id 会让另一次结果误被当作 fulfilled。

    def _microcompact(messages: list[dict[str, Any]]) -> list[dict[str, Any]]:
        """Replace old compactable tool results with one-line summaries."""
        compactable_indices: list[int] = []
        for idx, msg in enumerate(messages):
            if msg.get("role") == "tool" and msg.get("name") in _COMPACTABLE_TOOLS:
                compactable_indices.append(idx)

        if len(compactable_indices) <= _MICROCOMPACT_KEEP_RECENT:
            return messages

        stale = compactable_indices[: len(compactable_indices) - _MICROCOMPACT_KEEP_RECENT]
        updated: list[dict[str, Any]] | None = None
        for idx in stale:
            msg = messages[idx]
            content = msg.get("content")
            if not isinstance(content, str) or len(content) < _MICROCOMPACT_MIN_CHARS:
                continue
            name = msg.get("name", "tool")
            summary = f"[{name} result omitted from context]"
            if updated is None:
                updated = [dict(m) for m in messages]
            updated[idx]["content"] = summary

        return updated if updated is not None else messages
  1. 只收集 role=tool 且 name 在 _COMPACTABLE_TOOLS 的位置，不对所有工具结果一刀切。最近 _MICROCOMPACT_KEEP_RECENT 个保留。
  2. 旧结果还必须是字符串且达到长度阈值才被替换；结构化列表与短结果不会在本段被改写。
  3. 替换保留 role/name/tool_call_id，只缩小 content 为 result omitted from context。消息协议的关联仍存在；这不是知识归档，也没有生成一段语义摘要。

9. AgentRunner._snip_history：总预算计算

历史片段预算之后，还要把系统消息和工具定义纳入请求级估算。此摘录展示决定是否需要 snip 和尾部候选选择。

当前源码原文 · nanobot/agent/runner.py · AgentRunner._snip_history：总预算计算 · 第 1110–1152 行（连续摘录）

    def _snip_history(
        self,
        spec: AgentRunSpec,
        messages: list[dict[str, Any]],
    ) -> list[dict[str, Any]]:
        if not messages or not spec.context_window_tokens:
            return messages

        provider_max_tokens = getattr(getattr(self.provider, "generation", None), "max_tokens", 4096)
        max_output = spec.max_tokens if isinstance(spec.max_tokens, int) else (
            provider_max_tokens if isinstance(provider_max_tokens, int) else 4096
        )
        budget = spec.context_block_limit or (
            spec.context_window_tokens - max_output - _SNIP_SAFETY_BUFFER
        )
        if budget <= 0:
            return messages

        estimate, _ = estimate_prompt_tokens_chain(
            self.provider,
            spec.model,
            messages,
            spec.tools.get_definitions(),
        )
        if estimate <= budget:
            return messages

        system_messages = [dict(msg) for msg in messages if msg.get("role") == "system"]
        non_system = [dict(msg) for msg in messages if msg.get("role") != "system"]
        if not non_system:
            return messages

        system_tokens = sum(estimate_message_tokens(msg) for msg in system_messages)
        remaining_budget = max(128, budget - system_tokens)
        kept: list[dict[str, Any]] = []
        kept_tokens = 0
        for message in reversed(non_system):
            msg_tokens = estimate_message_tokens(message)
            if kept and kept_tokens + msg_tokens > remaining_budget:
                break
            kept.append(message)
            kept_tokens += msg_tokens
        kept.reverse()
  1. 没有 messages 或窗口上限时直接返回。max_output 优先取 spec.max_tokens 的整数，否则取 Provider generation 或4096。
  2. budget 使用 context_block_limit 或窗口减输出预留与安全缓冲；非正预算也直接返回，不能把这个分支解释为已经消除了超限风险。
  3. estimate_prompt_tokens_chain 同时接收 messages 与 tools.get_definitions；只有估算超预算才裁剪。system 消息完整复制保留，非 system 从新到旧累计。
  4. remaining_budget 至少128，至少保留一条候选。函数后半段恢复最近 user 并处理合法工具边界，因此最终值仍可能超预算；这是避免无效协议的明确取舍。

先固定一个手算 Session：[u1,a1,u2,a2(c1,c2),t(c1),a3]。每条估算成本依次为 [20,30,20,10,40,15]，last_consolidated=0，max_messages=6，max_tokens=70。a2 声明两个工具调用，但中断只留下 c1 结果。

独立搭建本章最小模块

从零实现纯函数 compile_context(history,current,system,budget)，返回合法消息列表和诊断信息 {estimated_tokens, over_budget, dropped_ids, backfilled_ids}。仅使用固定 token 计数器与虚拟图片块；不读取真实图片、不调用 Provider。实现回放投影、角色合并、尾部预算、孤立结果删除和缺失结果补位。

展开参考方案：结构、算法与错误处理
  1. 输入深复制用于练习，role 限定为 system/user/assistant/tool；只把批准的协议字段复制到输出。不要把任意 Session metadata 带进请求。
  2. 先选尾部预算，再恢复最近用户轮。诊断里保留 over_budget=True，不能以返回了列表冒充满足硬预算。
  3. 合并当前输入时，str+str 用空行；任何一边是 blocks 就把字符串转换成 text block。图片块保持字典结构，不用 str(list) 破坏协议。
  4. 扫描声明集合，删除有 id 却未声明的结果；再次扫描找缺失，紧跟同一 assistant 的已有工具结果插入错误占位。用已占用 id 校验拒绝重复调用标识。
  5. 参考教学算法：candidate=tail_by_budget(project(history)); candidate=recover_user(candidate,history); messages=merge_current([system,*candidate],current); messages=drop_orphans(messages); messages=backfill_missing(messages); return messages,diagnostics。该算法用于练习，不声称完整复刻生产前处理的调用顺序。

验收条件

  1. 按上面的70预算样例输出85 token的最近完整轮，并显式 over_budget=True；原 history 逐字段不变。
  2. t(x) 被删且 dropped_ids=[x]；c2补的是错误文本且 backfilled_ids=[c2]；FakeTool 执行次数为0。
  3. 历史以 user 结尾时合并为单个 user；图片字典仍是 image_url block，原字符串未被就地改写。
  4. 连续运行 compile_context 不再重复补同一个结果；重复 call_id 输入得到明确诊断。
  5. 极大 system 与极小预算不能标成“已经完全满足窗口”；诊断指出系统开销无法靠历史截断解决。

边界、不变量与容易写错的地方

  1. 预算估算不等于模型实际计费 token，且图片、工具 schema、厂商消息包装会影响成本。用“字符数/4”只能做粗略教学估算。
  2. 系统 prompt、历史、当前消息和工具定义是不同成本来源；只压缩 history 无法解决无限增大的 system 或 schema。
  3. Runtime Context 的 metadata-only 标签表达来源语义，不是代码沙箱，也不能把不可信内容自动提升为系统指令。
  4. 上下文删除、持久化删除和长期归档是不同操作；_microcompact 和 _snip_history 针对本轮请求，不直接代表用户消息被永久删除。
  5. 工具声明与结果按 call_id 配对，缺失结果补位不是工具成功；工具名相同也不能替代 id。
  6. ContextBuilder 处理图片不等于拥有任意路径访问权限；路径授权应在上游文件/媒体边界落实，不能因存在本函数就绕过工作区规则。
