# 学习手册复习题折叠答案设计

## 目标

为学习手册中的每一道复习题提供符合当前 nanobot 源码实现的答案。答案与问题保存在同一 HTML 页面，默认折叠，可通过鼠标或键盘展开。

## 覆盖范围

- 覆盖标题包含“自测”“能回答”“能解释”或“本章要解决”的 60 个问题块。
- 额外覆盖 `09-slash-command-system/07-channels-extension.html` 中“测试与源码地图”下的 3 道复习题。
- 合计 61 个问题块、211 道问题。
- `06-tools-mcp-extensions/06-extension-guide.html` 中的 7 项“上线前安全清单”仍作为执行检查项，不添加标准答案。

## HTML 结构

每一道题使用以下语义结构：

```html
<li>
  <span class="review-question">问题</span>
  <details class="answer-reveal">
    <summary>查看答案</summary>
    <div class="answer-content">
      <p>基于当前源码的答案。</p>
    </div>
  </details>
</li>
```

`details` 未设置 `open`，所以浏览器默认折叠；`summary` 原生支持鼠标、触摸和键盘操作，不引入额外 JavaScript 状态。

## 内容规则

- 先直接回答“为什么/如何”，再说明实际对象、字段或控制流。
- 关键处使用 `code` 标记类名、方法名、状态名和字段名。
- 答案只描述当前仓库实现；设计意图与代码事实不完全相同时，明确区分。
- 章节首页答案负责串联概念，子页面答案负责解释具体机制与边界。
- 不把答案写成正文的机械复述，也不承诺源码没有提供的隔离、安全或可靠性。

## 样式与可访问性

- 问题保持现有绿色勾选标记。
- 展开控件使用独立边框、浅色背景和清晰的 focus 样式。
- 展开后将按钮文案切换为“收起答案”，通过 CSS 生成，不依赖脚本。
- 深色主题和窄屏沿用现有变量与响应式布局。

## 验证

- 静态校验必须识别恰好 61 个复习块和 211 道题。
- 每道题必须恰好包含一个 `details.answer-reveal`。
- 每个答案必须包含非空的 `.answer-content`。
- 原有链接、HTML 页面元数据、目录注册和 JavaScript 语法校验继续通过。
