# 全书阅读导航审查与修复

日期：2026-09-07。范围：11 章、75 个章节内容页面，495 个正文二级小节；另检查手册首页既有导航。

## 发现的问题与处理

| 原问题 | 用户影响 | 修复 |
|---|---|---|
| 实作入口只有锚点链接，缺少页内前后导航 | 点击契约后，不知道数据流图在何处 | 常驻显示当前小节与序号，并提供上一节、下一节 |
| 页面与小节使用近似称谓 | 容易把一篇长文中的小节理解为独立章节 | 区分本章页面、本页目录、下一节、下一页、下一章 |
| 概览、移动端选择器和面试题返回链接只在页首 | 深入正文后失去返回入口 | 底部常驻本章概览；保留来源页或原题返回入口 |
| 桌面侧栏先列全书，再列本章 | 本章路线被 11 章目录挤到后面 | 本章页面置顶，全书章节仍保留 |
| 章末“下一页”回首页 | 连续阅读被中断 | 依目录进入下一章，最后一章才结束 |
| 实作页快捷入口存在“数据契约/数据流程”等不同名称 | 与来源页按钮难以对应 | 契约、数据流、源码、设计入口使用同一名称 |
| 普通页面大多数二级标题没有锚点 | 无法直接定位或列出本页目录 | 为缺失的标题生成稳定锚点，保留已有源码与题目锚点 |
| 跨页锚点没有来源信息 | 无法回到发起阅读的专题 | 对手册内部锚点链接记录经过目录校验的来源页面 |
| 题库筛选会隐藏分类 | 固定目录可能跳到隐藏内容 | 本页目录和前后导航同步过滤隐藏分类，无结果时提示调整筛选 |

## 设计与兼容性

采用共享静态脚本和小节目录，不拆分原有长文，不依赖后端、外部资源或浏览器历史。固定底部导航避开原有顶部栏和题库筛选区；手机适配、键盘焦点、Esc 关闭目录、减少动态效果及打印隐藏导航均已处理。正文底部预留空间，可滚动阅读被浮层暂时覆盖的内容。

来源参数只接受已注册的章节/页面标识；原题只接受 q01–q40。外部地址不被用作返回目的地。本章概览与来源页分开：前者回所在章，后者回发起阅读的页面。直接打开链接时无需来源参数，也始终能回概览或继续阅读。

`tools/build_reading_navigation.py` 生成小节目录及缺失锚点。`tools/integrate_handbook.py` 和仓库中的题库生成器已接入此步骤，防止后续生成覆盖导航。维护者调整章节顺序时只需维护原有 catalog；正文标题顺序决定页内阅读顺序。

## 验证

- 静态结构检查：76 个 HTML 页面、站内链接与锚点、离线资源、211 道原有回答及 40 道面试题。
- 原导航执行检查：所有页面的选中状态、前一页/概览/后一页的精确目标，以及跨章衔接。
- 新导航路由检查：75 页、570 个阅读位置，覆盖全部小节顺序、9 篇实作的契约到数据流、首尾边界、来源参数和筛选。
- 浏览器实测：概览→契约→数据流→概览，历史返回、390 像素窄屏目录、原题→模块→原题、默认答案折叠、无匹配筛选。
- 独立复制检查：把 study 单独复制至临时目录，执行结构检查、两套导航检查和教学示例验证。

复现检查命令见 README。浏览器仅以本机临时静态服务器验证交互，不调用项目 LLM 或外部服务。
